# Happy Birthday website

This is a static website that can be published with GitHub Pages.

## Publish with GitHub Pages

1. Create a **public** GitHub repository.
2. Add and push the files in this folder to the repository's `main` branch.
3. In the repository, open **Settings → Pages** and set the build and deployment source to **GitHub Actions**.
4. Open **Actions** and wait for **Deploy static website to GitHub Pages** to finish.
5. The public site URL will be shown in the workflow run and under **Settings → Pages**.

The site currently stores wishes in each visitor's browser. Wishes are not shared between visitors or devices. The owner access code is in the public JavaScript, so it is not a secure authentication mechanism.
